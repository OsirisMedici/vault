# Security policy

Use [GitHub’s private vulnerability report form](https://github.com/OsirisMedici/vault/security/advisories/new)
for a suspected vulnerability in Vault’s own code, patches, or release
tooling. Include the affected revision, the behavior you observed, its impact,
and reproduction steps using disposable data. Keep live credentials, vault
exports, session cookies, and recovery codes out of the report.

For vulnerabilities in an upstream component, use that project’s reporting
instructions. [Vaultwarden security](https://github.com/dani-garcia/vaultwarden/security/policy)
and [Bitwarden security](https://bitwarden.com/security/) cover the respective
upstream projects.

Use [GitHub Issues](https://github.com/OsirisMedici/vault/issues) for ordinary
bugs and setup questions.
